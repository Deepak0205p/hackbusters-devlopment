# Frontend - Sovereign On-Premise Agentic AI Workbench (SIH26117)

This directory contains the Next.js 14 (App Router) client application with Tailwind CSS, shadcn/ui (Radix UI), Framer Motion, and Zustand state stores.

- **Static Export Mode:** Configured with `output: 'export'` to generate `frontend/out/`.
- **Zero Python Code:** Contains strictly JavaScript, JSX, CSS, JSON, and Web assets.
- **Independent Build:** Runs via `npm install`, `npm run dev`, and `npm run build`.

# Local Tools Registry & Contracts
## Sovereign On-Premise Agentic AI Workbench (SIH26117)

Every tool in the system inherits from a standard abstract `BaseTool` interface, executes locally with zero external network connectivity, and returns structured outputs with standard error codes.

---

## 1. Tool Catalog Overview

| Tool Name | Class Name | Underlying Library / Engine | Primary Task |
| :--- | :--- | :--- | :--- |
| **`docker_python_sandbox`** | `DockerSandboxTool` | Docker Engine (`python:3.11-slim`, `--network none`) | Safe execution of mathematical, engineering & automation scripts. |
| **`paddle_ocr_engine`** | `PaddleOCRTool` | PaddleOCR / Tesseract (Local ONNX/PyTorch) | Text, table & tag extraction from scanned PDFs and diagrams. |

| **`network_sovereignty_watchdog`** | `SovereigntyWatchdogTool` | `psutil` + `scapy` / `pyshark` | Continuous socket inspection and verification of 0 external packets. |

## 2. Tool Input & Output Contracts

### 2.1. `docker_python_sandbox`
- **Purpose:** Executes Python code generated by Qwen 2.5 Coder in an isolated container without network access.
- **Input Parameters:**
  - `code` (string, required): Complete Python script to execute.
  - `timeout_seconds` (integer, optional, default: `15`): Execution deadline.
- **Output Schema:**
```json
{
  "exit_code": 0,
  "stdout": "Calculated Hydraulic Power: 26.04 kW\nEfficiency: 74.4%",
  "stderr": "",
  "execution_time_ms": 420,
  "generated_artifacts": ["output_plot.png"]
}
```
- **Error Behavior:** If `exit_code != 0`, `stderr` contains full traceback, enabling the LangChain ReAct loop to iterate and self-correct up to 10 times.

### 2.2. `paddle_ocr_engine`
- **Purpose:** Extracts structured text, numerical tables, and diagram labels from scanned documents and images.
- **Input Parameters:**
  - `file_path` (string, required): Local path to image or PDF in `data/sample_inputs/`.
  - `extract_tables` (boolean, optional, default: `true`): Flag to extract tabular layout.
- **Output Schema:**
```json
{
  "status": "SUCCESS",
  "text_blocks": [
    {"text": "FURNACE TUBE SKIN TEMP: 620 C", "confidence": 0.98, "box": [120, 45, 340, 70]},
    {"text": "CORROSION RATE: 0.45 mm/yr", "confidence": 0.96, "box": [120, 80, 310, 105]}
  ],
  "raw_text": "FURNACE TUBE SKIN TEMP: 620 C\nCORROSION RATE: 0.45 mm/yr"
}
```

---

### 2.3. `docx_generator`
- **Purpose:** Generates formatted Microsoft Word approval notes with standard MRPL headers, signatures, and SOP citations.
- **Input Parameters:**
  - `title` (string, required): Document title (e.g., "URGENT APPROVAL NOTE: FURNACE F-101 DECOKING").
  - `sections` (list of objects, required): Array of `{heading: string, content: string}`.
  - `metadata` (object, optional): Author, date, reference SOP clause numbers.
  - `output_filename` (string, required): Name of target `.docx` file.
- **Output Schema:**
```json
{
  "status": "SUCCESS",
  "file_path": "data/outputs/docx/approval_note_F101.docx",
  "file_size_bytes": 34812,
  "download_url": "/api/files/download/approval_note_F101.docx"
}
```

---

### 2.4. `xlsx_generator`
- **Purpose:** Generates structured Excel asset registers and numerical calculation workbooks with formulas and styled headers.
- **Input Parameters:**
  - `sheet_name` (string, required): Name of the worksheet.
  - `headers` (list of strings, required): Column titles (e.g., `["Tag", "Equipment", "Rating", "Maintenance Flag"]`).
  - `rows` (list of lists, required): Row data values.
  - `output_filename` (string, required): Name of target `.xlsx` file.
- **Output Schema:**
```json
{
  "status": "SUCCESS",
  "file_path": "data/outputs/xlsx/asset_register.xlsx",
  "total_rows": 9,
  "download_url": "/api/files/download/asset_register.xlsx"
}
```

---

### 2.5. `pptx_generator`
- **Purpose:** Compiles technical data into formatted PowerPoint presentation decks.
- **Input Parameters:**
  - `presentation_title` (string, required): Deck title.
  - `slides` (list of objects, required): Array of `{title: string, bullet_points: list[string]}`.
  - `output_filename` (string, required): Name of target `.pptx` file.
- **Output Schema:**
```json
{
  "status": "SUCCESS",
  "file_path": "data/outputs/pptx/turnaround_strategy.pptx",
  "total_slides": 4,
  "download_url": "/api/files/download/turnaround_strategy.pptx"
}
```

---

### 2.6. `chroma_sop_search`
- **Purpose:** Queries local vector store for MRPL refinery manuals and safety procedures with exact clause provenance.
- **Input Parameters:**
  - `query` (string, required): Semantic search question or technical clause topic.
  - `top_k` (integer, optional, default: `3`): Number of relevant document chunks.
- **Output Schema:**
```json
{
  "results": [
    {
      "source_document": "SOP-MRPL-FURNACE-01.pdf",
      "clause": "Clause 4.1.2 - Skin Temperature Limits",
      "page": 14,
      "score": 0.892,
      "text": "When furnace tube skin temperature exceeds 610°C, decoking turnaround must be scheduled within 7 calendar days."
    }
  ]
}
```

### 2.7. `network_sovereignty_watchdog`
- **Purpose:** Inspects active network sockets and packet capture buffers to verify zero outbound egress.
- **Input Parameters:** None
- **Output Schema:**
```json
{
  "verdict": "SOVEREIGN",
  "external_packet_count": 0,
  "active_local_listeners": ["127.0.0.1:8000", "127.0.0.1:11434"],
  "non_local_traffic_detected": false
}
```
